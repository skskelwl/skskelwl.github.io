[지난 글](/posts/openarm-project-overview/)에서는 OpenArm 프로젝트의 전체 구조를 살펴봤다. 이번에는 **OpenArm 1.0을 실제로 제작하기 전에 무엇을 준비해야 하는지** 공식 BOM을 기준으로 정리한다.

이 글의 수량은 공식 문서가 제시하는 **양팔 2개 + 페데스탈 1개 + 그리퍼 2개** 구성 기준이다. 단일 팔만 제작한다면 팔 전용 부품은 줄일 수 있지만, 페데스탈·비상 정지 장치·제어 PC 같은 공용 부품까지 무조건 절반으로 줄이면 안 된다.

> OpenArm 2.0의 CAD나 부품을 1.0 목록과 섞지 않는 것이 중요하다. 주문 전에 사용할 버전의 CAD, BOM, 배선 도면을 한 폴더에 고정해 두는 편이 안전하다.

## 1. 관절 모터

OpenArm 1.0은 팔 하나에 7개 관절과 그리퍼 구동용 J8 모터를 사용한다. 양팔 기준으로 총 16개가 필요하다.

| 적용 위치 | 모델 | 수량 |
| --- | --- | ---: |
| J1, J2 | DM-J8009P-2EC | 4 |
| J3 | DM-J4340P-2EC | 2 |
| J4 | DM-J4340-2EC | 2 |
| J5, J6, J7, J8 | DM-J4310-2EC V1.1 | 8 |
| **합계** |  | **16** |

![OpenArm 1.0 관절별 모터 배치](/assets/img/posts/openarm-1/openarm-1-motors.webp){: width="700" height="400" }
_관절별 DAMIAO 모터 배치. 이미지 출처: [OpenArm 1.0 모터 사양](https://docs.openarm.dev/1.0/hardware/specifications/motor/)_

모터를 주문할 때는 모델명 끝의 `P`, `2EC`, 버전 표기까지 확인해야 한다. 외형이 비슷하더라도 감속비, 출력축, 베어링 구조가 다르면 기구부와 맞지 않을 수 있다. 조립 전에 각 모터의 CAN ID를 설정해야 하므로 모터만 따로 연결할 시험 환경도 필요하다.

## 2. 팔 기구부

팔 기구부는 **주문 제작품**과 **기성품**으로 나뉜다.

### 주문 제작품

공식 BOM에는 J1부터 J8까지 총 27종의 부품이 등록되어 있다. 좌우 공용 부품 외에 `J6_C_left/right`, `J7_D_left/right`처럼 좌우 형상이 다른 부품도 있으므로 수량과 방향을 반드시 구분해야 한다.

- Al6061 CNC 절삭 부품
- SUS304 절곡·절삭 부품
- 양팔 기준 공식 추정 비용: **¥316,018**
- 공식 제작 방식: MISUMI MEVIY에 등록된 모델 번호 또는 STEP 파일 사용

국내 가공 업체를 이용할 수도 있지만, 소재·판 두께·나사 규격·공차를 원본과 동일하게 지정해야 한다. 견적 전에는 [OpenArm 하드웨어 저장소](https://github.com/enactic/openarm_hardware)의 v1 CAD와 공식 문서의 모델 번호가 같은 버전인지 대조하는 것이 좋다.

### 기성품

볼트류까지 포함한 양팔 기준 수량은 다음과 같다.

| 종류 | 규격 | 수량 |
| --- | --- | ---: |
| 육각렌치 볼트 | M3×6 / M3×8 / M3×15 / M3×18 | 146 / 38 / 24 / 12 |
| 육각렌치 볼트 | M4×6 / M4×8 / M4×10 | 16 / 16 / 24 |
| 육각렌치 볼트 | M5×10 | 24 |
| 양단 탭 원형 포스트 | 61 mm / 74.2 mm | 2 / 4 |
| 스텝 볼트 | DBSY4-6-5 | 4 |
| 베어링 | MR106ZZ1 / FL6700ZZ / FL6803ZZ | 4 / 4 / 2 |
| 초박형 수지 와셔 | SWSPS12-6-0.5 | 8 |

볼트는 조립 중 분실하거나 나사산이 손상될 수 있으므로 소량의 예비분을 함께 준비하는 편이 낫다. 베어링과 와셔는 치수가 비슷해 보여도 임의 대체하지 말고 내경·외경·두께를 모두 확인해야 한다.

## 3. 페데스탈

양팔을 지지하는 중앙 프레임은 다음 부품으로 구성된다.

| 부품 | 규격·모델 | 수량 |
| --- | --- | ---: |
| 알루미늄 프로파일 | 60×60×750 mm, HFSB6-6060-750 | 1 |
| 보강 브래킷 | 30×60, 60° | 1 |
| 앵글 브래킷 세트 | M6, 30/60 | 2 |
| M6 볼트 | M6×12 | 8 |
| 후입 스프링 너트 | HNTP6-6 | 8 |
| 베이스 플레이트 | 250×190 mm, Al6061 CNC | 1 |

프로파일에 팔을 장착하기 전에 T-slot 너트 위치를 잡아 두어야 한다. 완성된 양팔은 무게와 관성이 크므로 베이스 플레이트를 평평하고 튼튼한 작업대에 추가로 고정할 방법도 미리 계획해야 한다.

## 4. 그리퍼

그리퍼 2개에는 기성품과 주문 제작품이 모두 필요하다.

### 기성품

| 부품 | 모델 | 수량 |
| --- | --- | ---: |
| 미니어처 리니어 가이드 | RSE2B10-155 | 2 |
| M3×5 / M3×8 볼트 | CBE3-5 / CBE3-8 | 8 / 20 |
| 소두 M3×6 볼트 | KBBS3-6 | 32 |
| 스텝 볼트 | DBSY4-5-4 | 8 |
| 베어링 | MR126ZZ | 8 |

### 주문 제작품

- `rail_connector` 2개
- `swivel_rotor` 2개
- `swivel_link` 4개
- `rail_CNC_attachment` 4개

그리퍼는 리니어 가이드, 링크와 베어링의 정렬이 동작 품질에 직접 영향을 준다. 조립 후에는 손으로 천천히 움직여 걸림이 없는지 확인한 다음 J8 모터를 연결해야 한다.

## 5. 전원·통신·배선

전장품은 로봇을 움직이기 전에 별도의 테이블 테스트가 필요하다.

| 부품 | 수량 | 비고 |
| --- | ---: | --- |
| USB2CANFD 변환기 | 2 | 좌·우 팔에 각각 사용 |
| 24 V 전원공급장치 | 2 | 공식 가이드 예시는 24 V, 15 A |
| 허브 PCB | 2 | Gerber·BOM·CPL로 제작·실장 가능 |
| PCB 커넥터 | 12 | LCSC 조립 옵션 사용 시 별도 구매 여부 확인 |
| J1/J2–Hub 케이블 | 4 | 공식 케이블 도면 사용 |
| J3+J4–Hub 케이블 | 2 | 공식 케이블 도면 사용 |
| J4+J5+J6+J7–Hub 케이블 | 2 | 공식 케이블 도면 사용 |
| J7–J8 케이블 | 2 | 공식 케이블 도면 사용 |
| 통신 케이블 | 2 | 공식 케이블 도면 사용 |
| 전원 연장 케이블 | 2 | 공식 케이블 도면 사용 |
| 비상 정지 스위치 | 1 | 손이 즉시 닿는 위치에 설치 |

![24 V 전원과 USB-CAN을 이용한 단일 모터 시험 구성](/assets/img/posts/openarm-1/openarm-1-can-setup.webp){: width="1400" height="954" }
_조립 전 단일 모터 시험 구성 예시. 실제 전체 시스템은 공식 허브 PCB와 하네스 도면을 따른다._

전원을 처음 넣을 때는 전체 팔을 한 번에 연결하지 않고 다음 순서로 확인하는 것이 안전하다.

1. 전원공급장치의 출력 전압과 극성을 멀티미터로 확인한다.
2. 비상 정지 스위치가 전원을 실제로 차단하는지 확인한다.
3. USB2CANFD와 모터 하나만 연결한다.
4. 모터 검색, CAN ID, 통신 속도를 확인한다.
5. 저속·저토크 제한에서 회전 방향을 확인한다.
6. 검증한 모터를 한 개씩 추가한다.

> 24 V 대전류 전원을 다루므로 노출 단자와 역극성에 특히 주의해야 한다. 전원이 켜진 상태에서 커넥터를 탈착하지 말고, 최초 시험은 전류 제한을 사용할 수 있는 환경에서 진행하는 편이 안전하다.
{: .prompt-danger }

## 6. 제작 공구와 개발 환경

공식 BOM에는 포함되지 않지만 실제 조립에는 다음 항목이 필요하다.

### 필수에 가까운 공구

- M3~M6 볼트에 맞는 육각렌치와 육각 비트
- 작은 체결부에 사용할 정밀 드라이버
- 디지털 멀티미터
- 와이어 스트리퍼와 규격에 맞는 압착 공구
- 납땜 인두, 납, 플럭스, 열수축 튜브
- 버니어 캘리퍼스
- 케이블 라벨과 케이블 타이
- 보안경과 절연 작업 매트

토크 드라이버와 저강도 나사 고정제는 반복 구동 시 체결 풀림을 관리하는 데 유용하지만, 적용 위치와 조임 토크는 모터 및 체결부 사양을 확인한 뒤 결정해야 한다.

### 개발 환경

- Ubuntu 22.04 이상 PC
- USB 포트 2개 이상 또는 안정적인 전원형 USB 허브
- Git, ROS 2, CAN 유틸리티
- `openarm_can`, `openarm_description`, `openarm_ros2`
- RViz 및 필요에 따라 MoveIt 2

실물 조립과 별개로 URDF/Xacro 모델을 먼저 RViz에서 열어 관절 순서, 영점, 회전 방향과 제한을 익혀 두면 초기 구동 실수를 줄일 수 있다.

## 추천 주문 순서

납기와 재가공 위험을 고려하면 다음 순서가 효율적이다.

1. **버전 고정**: OpenArm 1.0 CAD, BOM, 배선 파일을 같은 릴리스로 저장
2. **모터 확보**: 정확한 모델과 수량, 납기 확인
3. **주문 제작품 견적**: CNC·판금 업체와 소재·공차 검토
4. **기성 기구부 주문**: 볼트, 베어링, 포스트, 프레임
5. **PCB 발주**: Gerber, BOM, CPL 파일 버전 확인 후 주문
6. **하네스 발주·제작**: 공식 도면과 커넥터 방향 확인
7. **전원·CAN 시험 환경 구성**: 조립 전에 모터 ID와 통신 확인
8. **기구 조립**: 페데스탈부터 서브어셈블리 순서로 진행
9. **배선 및 케이스 장착**: 가동 범위 전체에서 케이블 간섭 확인
10. **저속 시운전**: 한 관절씩 영점과 방향 확인
